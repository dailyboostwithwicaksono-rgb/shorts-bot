Kebijakan Privasi

Kebijakan ini menjelaskan bagaimana shorts-bot (alat pribadi) mengakses dan menangani data saat menggunakan Google API.

Terakhir diperbarui: 20 November 2026

1. Ruang lingkup

shorts-bot adalah alat pribadi yang digunakan untuk menyiapkan dan mengunggah video YouTube Shorts ke channel YouTube milik pemilik. Aplikasi ini bukan layanan publik untuk pengguna lain.

2. Data Google yang diakses

Atas izin pemilik, aplikasi dapat mengakses data melalui Google API sesuai fungsi yang dijalankan. Untuk fungsi unggah, aplikasi menggunakan scope YouTube Data API yang diperlukan, seperti https://www.googleapis.com/auth/youtube.upload, guna mengunggah video dan metadata terkait (mis. judul, deskripsi, tag, dan pengaturan privasi) ke channel YouTube milik pemilik.

Aplikasi hanya meminta/mengakses data dan izin yang diperlukan untuk fungsi tersebut.

3. Cara penggunaan data

  • Data digunakan semata-mata untuk menyediakan fungsi yang diminta (mis. mengunggah konten ke channel milik pemilik).
  • Data tidak digunakan untuk menayangkan iklan.
  • Data tidak dijual kepada pihak ketiga.
  • Data tidak digunakan untuk tujuan lain di luar fungsi aplikasi.

4. Penyimpanan dan pemrosesan

Aplikasi dijalankan secara lokal/pribadi. Kredensial dan token akses (jika digunakan) disimpan secara lokal di perangkat milik pemilik dan tidak disediakan melalui server publik milik aplikasi ini. File video dan metadata diproses sesuai kebutuhan untuk menjalankan fungsi unggah/pengelolaan konten.

5. Pembagian data

Data tidak dibagikan kepada pihak ketiga, kecuali dikirim ke layanan Google (mis. YouTube/Google API) sebagaimana diperlukan untuk menjalankan fungsi yang diminta oleh pemilik.

6. Retensi dan pencabutan akses

Pemilik dapat mencabut akses aplikasi kapan saja melalui pengaturan akun Google (Keamanan → Aplikasi & layanan pihak ketiga). Token/kredensial lokal dapat dihapus dari perangkat kapan saja.

7. Kepatuhan

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

8. Perubahan kebijakan

Kebijakan ini dapat diperbarui dari waktu ke waktu agar tetap sesuai dengan fungsi aplikasi. Tanggal pembaruan terakhir akan dicantumkan di halaman ini.

9. Kontak

Untuk pertanyaan terkait privasi atau penggunaan aplikasi ini, silakan hubungi pemilik melalui kontak yang tercantum pada halaman Beranda.
